# Contributing to BirdTraitsR

Thanks for your interest in contributing! This project is under active development.

## How to Contribute

1. **Fork** this repository
2. **Clone** your fork locally
3. Create a new **branch** for your change:
4. Make your changes
5. Run `devtools::document()`, `devtools::load_all()`, and `devtools::check()` to confirm everything still passes
6. Commit your changes and push to your fork
7. Open a **Pull Request** describing what you changed and why

## Reporting Bugs

Please open an [Issue](https://github.com/ysuraj216-svg/BirdTraitsR/issues) with:
- A clear description of the problem
- Steps to reproduce it
- Your R version (`R.version.string`) and package version

## Code Style

- Follow the existing formatting conventions in the codebase
- Include roxygen2 documentation (`@param`, `@return`, `@examples`, `@export`) for any new exported function
- Ensure `devtools::check()` passes with 0 errors before submitting

## Questions

Feel free to open an Issue for any questions about contributing.
